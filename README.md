# BEATLINE

Unity로 제작한 Android 4레인 리듬게임의 테스트 빌드 저장소입니다.

## APK 다운로드

[BEATLINE v0.13.0 릴리스](https://github.com/NS-DDC/beatline/releases/tag/v0.13.0)에서 `Beatline.apk`를 다운로드하세요.

- Android 8.0 이상 / ARM64 / 가로 화면
- 한국어·영어 선택과 저장, 오프라인 번역·폰트
- 네온시티 곡 선택, 아티스트의 3곡 빠른 이동, 최근 플레이·즐겨찾기·장르 탐색
- 일반곡 42곡, Easy / Normal / Hard / Extreme Hard, 탭·홀드, 4레인 멀티터치
- 로컬 최고 기록, 14명 × 5개 = 70개 아티스트 도전과제·영구 메달
- 캡슐 노트·홀드 리본, 판정선 파동·콤보 피드백, 결과 점수·랭크·메달 모션
- APK: 773,916,530 bytes (738.06 MiB)
- 앱 ID: `com.beatline.local`, 버전 `0.13.0` / versionCode `130`

## 테스트 빌드 안내

기존 설치본과 같은 서명입니다. 기록 보존을 위해 기존 앱을 삭제하지 않고 업데이트 설치하세요. 실기기 업데이트 설치는 미검증입니다.

Unity EditMode 81/81, PlayMode 22/22, UI 보정 후 관련 6/6 검사, 최종 Windows Player 30/60/120FPS 세 조건, APK 패키지 13개 검사를 통과했습니다. Windows 입력은 합성 입력입니다. Android 실기기의 설치·오디오/터치 지연·성능은 미실행이며, 정밀 시계 오차 개선과 새 채보의 음악성 검수는 남아 있습니다.

내부 테스트용 사전 릴리스입니다. 포함된 음원의 상업 이용 권리 검토가 완료되지 않았으므로 상업 출시 승인 상태가 아닙니다.
