# BEATLINE

Unity로 제작한 Android 4레인 리듬게임의 테스트 빌드 저장소입니다.

## APK 다운로드

[BEATLINE v0.12.0 릴리스](https://github.com/NS-DDC/beatline/releases/tag/v0.12.0)에서 `Beatline.apk`를 다운로드하세요.

- Android 8.0 이상 / ARM64
- 가로 화면, 탭과 홀드, 4레인 멀티터치
- 일반곡 42곡, Easy / Normal / Hard / Extreme Hard
- 최근 플레이, 즐겨찾기, 장르 탐색, 로컬 최고 기록
- 네온시티 테마, 캡슐 탭·홀드 리본, 판정선 파동과 콤보 피드백
- 14명 × 5개 = 70개 아티스트 도전과제·메달, 영구 보관·기존 기록 소급 인정
- 결과 점수·랭크·메달 모션, 건너뛰기·연출 감소, 다음 도전 선택
- APK 크기: 751,648,113 bytes (716.83 MiB)
- 앱 ID: `com.beatline.local`
- 버전: `0.12.0` / versionCode `120`

## 테스트 빌드 안내

기존 BEATLINE 설치본과 같은 서명으로 제작했습니다. 기존 앱을 삭제하면 로컬 기록이 지워질 수 있으므로 설치 시 업데이트를 이용하세요.

Unity EditMode 72/72, PlayMode 20/20, Windows Player 3조건, APK 패키지 13개 검사를 통과했습니다. Android 실기기의 설치·오디오/터치 지연·성능은 아직 검증하지 않았으며, 정밀 시계 오차 개선과 새 채보의 음악성 검수가 남아 있습니다.

내부 테스트용 사전 릴리스입니다. 포함된 음원의 상업 이용 권리 검토가 완료되지 않았으므로 상업 출시 승인 상태가 아닙니다.
